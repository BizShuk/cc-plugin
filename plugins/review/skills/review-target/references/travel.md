# 旅行 (Travel)

旅行的成長不只是「去更多地方」，而是五個屬性：頻率、成本、體驗、旅行能力、紀錄。

## 診斷順序 (Diagnosis Order)

1. 一年出遊次數低於期望 → 主攻頻率，通常卡在假期規劃或預算。
2. 每趟花費超出預算 → 主攻成本。
3. 回來覺得累、記不得做了什麼 → 主攻體驗。
4. 語言、行李、自由行常卡關 → 主攻旅行能力。
5. 照片留在手機裡沒整理 → 主攻紀錄。

## 頻率 (Frequency)

| KPI            | 量測方式                    | 參考區間             |
| -------------- | --------------------------- | -------------------- |
| 每年旅行次數   | 自行統計                    | 相對去年成長         |
| 特休使用率     | 已用特休 ÷ 可用特休         | 年底前用完           |

| 行動           | 具體動作                                                                                 | 份量／頻率                     |
| -------------- | ---------------------------------------------------------------------------------------- | ------------------------------ |
| 年度假期規劃   | 依人事行政總處公告的年度行事曆，在行事曆標出連假，搭 1-2 天特休接成 4-5 天假期            | 每年 1 月排出 2-4 個出遊窗口   |
| 旅行基金       | 開一個子帳戶，每月自動轉入 年度旅行預算 ÷ 12                                             | 每月發薪日                     |
| 近程短旅       | 國內或近程航線的 2-3 天旅行                                                              | 每季 1 次                      |

## 成本 (Cost)

| KPI                  | 量測方式                                                   | 參考區間                       |
| -------------------- | ---------------------------------------------------------- | ------------------------------ |
| 每人每日花費         | 不含機票，旅程結束後結算                                   | 相對上一趟下降或持平           |
| 機票價格             | 對照 Google Flights 顯示的「價格偏低／一般／偏高」區間     | 落在偏低或一般                 |
| 里程兌換價值         | 省下的現金 ÷ 花掉的里程                                     | 相對自身過去兌換比較           |

| 行動           | 具體動作                                                                                             | 份量／頻率                    |
| -------------- | ---------------------------------------------------------------------------------------------------- | ----------------------------- |
| 追蹤機票       | Google Flights 開啟「追蹤價格 (Track prices)」，用日期方格找最便宜日期；目的地未定時用「探索 (Explore)」地圖 | 出發前 3-6 個月開始追蹤  |
| 比較出發日     | Skyscanner 用「整月」檢視比較同一航線                                                                | 每趟                          |
| 訂票時點       | 經驗值：近程航線 1-3 個月前、長程 2-6 個月前；連假與旺季再提早                                        | 每趟                          |
| 住宿比價       | 同區域比較 Booking.com、Agoda、Airbnb，先訂可免費取消的方案，出發前 7 天再比價一次                   | 每趟                          |
| 里程累積       | 集中累積 1 個航空聯盟（星空聯盟、寰宇一家、天合聯盟）；刷卡選海外回饋高、海外手續費低的卡             | 持續                          |
| 當地支付       | 使用多幣別帳戶或外幣卡，避免在機場換匯                                                               | 每趟                          |

## 體驗 (Experience)

| KPI                  | 量測方式                                   | 參考區間             |
| -------------------- | ------------------------------------------ | -------------------- |
| 在地限定體驗數       | 每趟只有當地才能做的活動數                 | 每趟 2 個以上        |
| 行程密度             | 每天固定行程數                             | 每天 1-2 個          |
| 旅後滿意度           | 回程 3 天內自評 1-10 分                    | 逐趟上升             |

| 行動           | 具體動作                                                                       | 份量／頻率                |
| -------------- | ------------------------------------------------------------------------------ | ------------------------- |
| 留白行程       | 每天最多 1-2 個固定行程 (Anchor)，其餘時間留白；每 3 天安排半天完全空白          | 每趟                      |
| 慢旅行         | 每個據點至少住 3 晚，減少移動日                                                | 每趟                      |
| 在地體驗       | 市場導覽、料理課、在地導覽，透過 KKday、Klook 或 Airbnb 體驗預訂                | 每趟至少 1 個             |
| 當地用語       | 出發前用 Duolingo 或短片學 10 句：你好、謝謝、不好意思、多少錢、好吃           | 出發前 2 週，每天 10 分鐘 |
| 旅後評分       | 給這趟打 1-10 分，寫下「下次會改的一件事」                                     | 回程 3 天內               |

## 旅行能力 (Travel Skills)

| KPI                  | 量測方式                                   | 參考區間                 |
| -------------------- | ------------------------------------------ | ------------------------ |
| 只帶登機箱的比例     | 只帶登機箱的趟數 ÷ 總趟數                  | 逐年上升                 |
| 自由行次數           | 不跟團的趟數                               | 相對現況成長             |
| 獨旅次數             | 一個人出發的趟數                           | 依個人目標               |

| 行動           | 具體動作                                                                                             | 份量／頻率          |
| -------------- | ---------------------------------------------------------------------------------------------------- | ------------------- |
| 輕裝           | Apple 備忘錄建立核取清單 + 收納袋 (Packing cubes)，衣物以 3 天份輪替洗滌；多數亞洲廉航手提行李上限約 7 kg，以航空公司公告為準 | 每趟出發前 |
| 離線準備       | Google 地圖下載離線地圖並存「想去」清單；Google 翻譯下載離線語言包，使用相機翻譯                      | 出發前 1 天         |
| 交通預查       | 查好機場到住宿的路線與票種，例如交通卡或周遊券                                                       | 出發前 1 週         |
| 獨旅第一步     | 選治安佳、交通方便的近程城市，住 2-3 晚                                                               | 第一趟              |

## 紀錄 (Documentation)

| KPI                  | 量測方式                              | 參考區間        |
| -------------------- | ------------------------------------- | --------------- |
| 整理完成的相簿       | 每趟是否有一本精選相簿                | 每趟 1 本       |
| 旅行日記完成率       | 有寫日記的天數 ÷ 旅行天數             | 100%            |
| 發布內容數           | 每趟發布的貼文或影片                  | 每趟 1 則以上   |

| 行動           | 具體動作                                                                                       | 份量／頻率          |
| -------------- | ---------------------------------------------------------------------------------------------- | ------------------- |
| 每日紀錄       | 睡前在 Apple 備忘錄或 Day One 寫 3 行，挑 3 張當天代表照                                       | 每晚 5 分鐘         |
| 共享相簿       | iPhone 照片為每趟建立共享相簿，同行者一起放照片                                                | 每趟                |
| 旅後內容       | 挑 10-20 張做成輪播貼文，或剪一支 30 秒 Reel（接 `social-media.md`）                           | 回程 7 天內         |
| 年度回顧       | 把全年旅行做成一本相片書或一篇年度回顧                                                         | 每年 12 月          |
