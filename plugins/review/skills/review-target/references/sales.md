# 銷售 (Sales)

銷售的成長可以用`銷售速度 (Sales Velocity)` 一條公式串起來：

```text
銷售速度 = 商機數 × 成交率 × 平均客單價 ÷ 銷售週期天數
```

商機數對應開發，成交率與週期對應成交，平均客單價對應客單價；
面對一般消費者的零售與電商另有自己的漏斗，已成交客戶的再成長歸在客戶擴展。

## 診斷順序 (Diagnosis Order)

1. 算出漏斗各階段轉換率（名單 → 會議 → 提案 → 成交）；沒有紀錄時，第一個行動就是建 CRM。
2. 商機覆蓋率 (Pipeline coverage) = 在手商機金額 ÷ 目標業績，低於 3 倍（經驗值）→ 主攻開發。
3. 覆蓋率足夠但成交率低 → 主攻成交。
4. 成交率正常但業績不夠 → 主攻客單價。
5. 新客穩定但總營收停滯 → 主攻客戶擴展，代表流失正在抵銷新增。
6. 面對一般消費者的線上或門市銷售 → 直接看電商與門市。

## 開發 (Prospecting)

| KPI              | 量測方式                                   | 參考區間                           |
| ---------------- | ------------------------------------------ | ---------------------------------- |
| 每週新名單數     | CRM 新增筆數                               | 相對現況成長                       |
| 每日觸及數       | 外撥電話、Email、LinkedIn 訊息總數         | 開發期每天 20 次                   |
| 回覆率           | 回覆數 ÷ 觸及數                            | 冷開發 Email 常見個位數百分比      |
| 每週預約會議數   | 行事曆統計                                 | 相對現況成長                       |
| 商機覆蓋率       | 在手商機金額 ÷ 目標業績                    | 3 倍以上（經驗值）                 |

| 行動           | 具體動作                                                                                                   | 份量／頻率                  |
| -------------- | ---------------------------------------------------------------------------------------------------------- | --------------------------- |
| 定義 ICP       | 寫出理想客戶輪廓 (Ideal Customer Profile)：產業、規模、職稱、觸發事件（募資、擴編、換系統），放在 CRM 首頁 | 一次寫好，每季檢視          |
| 目標名單       | 從 LinkedIn Sales Navigator、公司官網、產業名錄整理 100 家，匯入 HubSpot 免費 CRM 或試算表                 | 一次 100 家，每月補充       |
| 開發時段       | 行事曆鎖定固定時段，只做個人化觸及                                                                         | 每天 60 分鐘，20 次觸及     |
| 開發序列       | 同一對象在 2-3 週內接觸 5-7 次，混合 Email、LinkedIn、電話，每次都帶新資訊                                  | 每位名單                    |
| 冷開發 Email   | 120 字以內：一句對方的具體觀察 + 一個相關成果 + 一個低門檻邀請（「下週二 15 分鐘方便嗎？」）                | 每封                        |
| 轉介           | 客戶取得成果後 2 週內問「還有誰也遇到同樣的問題？」                                                        | 每位成功客戶                |

## 成交 (Closing)

| KPI              | 量測方式                                   | 參考區間             |
| ---------------- | ------------------------------------------ | -------------------- |
| 會議轉提案率     | 提案數 ÷ 首次會議數                        | 相對現況成長         |
| 成交率 (Win rate) | 成交數 ÷ 提案數                           | 相對現況成長         |
| 下一步明確率     | 會議結束時已排定下一步的比例               | 100%                 |
| 銷售週期         | 首次接觸到成交的天數                       | 相對現況縮短         |

| 行動           | 具體動作                                                                                                   | 份量／頻率                  |
| -------------- | ---------------------------------------------------------------------------------------------------------- | --------------------------- |
| 需求訪談       | SPIN 提問：現況 (Situation) → 問題 (Problem) → 影響 (Implication) → 需求回報 (Need-payoff)；自己講話時間控制在一半以內 | 每場首次會議  |
| 資格判斷       | BANT：預算、決策者、需求、時程；四項缺兩項以上就先補資訊，暫緩提案                                          | 每個商機                    |
| 排定下一步     | 會議結束前直接送出行事曆邀請或 Calendly 連結                                                                | 每場會議                    |
| 快速提案       | 附一頁摘要：問題、方案、效益數字、價格、下一步                                                              | 會議後 24 小時內            |
| 異議處理       | LAER：傾聽 (Listen) → 認同 (Acknowledge) → 探詢 (Explore) → 回應 (Respond)                                  | 每次異議                    |
| 追蹤節奏       | 提案後第 2、5、10 天各跟進一次，每次附新價值（案例、數據）                                                  | 每份提案                    |
| 錄音複盤       | 用 tl;dv 或 Zoom 錄影，挑一場輸掉的會議找出流失點                                                          | 每週 1 場                   |

## 客單價 (Deal Size)

| KPI              | 量測方式                              | 參考區間         |
| ---------------- | ------------------------------------- | ---------------- |
| 平均客單價       | 成交總額 ÷ 成交數                     | 相對現況成長     |
| 加購率           | 含加購項目的訂單 ÷ 總訂單             | 相對現況成長     |
| 平均折扣率       | 折扣金額 ÷ 牌價                       | 相對現況下降     |
| 年約比例         | 年約合約 ÷ 總合約                     | 相對現況成長     |

| 行動           | 具體動作                                                               | 份量／頻率          |
| -------------- | ---------------------------------------------------------------------- | ------------------- |
| 三方案定價     | 好、較好、最好三個方案，把希望成交的方案放中間                         | 每份報價            |
| 綁售           | 核心產品 + 導入服務或教育訓練                                          | 每份報價            |
| 折扣換條件     | 折扣只換取年約預付、案例授權或轉介                                     | 每次議價            |
| 成果時刻升級   | 客戶達成第一個成果時提出升級方案                                       | 每位客戶            |

## 電商與門市 (E-commerce & Retail)

| KPI                  | 量測方式                              | 參考區間                           |
| -------------------- | ------------------------------------- | ---------------------------------- |
| 轉換率               | 訂單數 ÷ 造訪數                       | 電商常見 1-3%，依產業差異大        |
| 購物車放棄率         | 放棄結帳 ÷ 加入購物車                 | Baymard 統計平均約 70%             |
| 平均訂單金額 (AOV)   | 營收 ÷ 訂單數                         | 相對現況成長                       |
| 回購率               | 90 天內再購的顧客比例                 | 相對現況成長                       |
| 評分與評論數         | 平台後台                              | 4.5 星以上，評論數逐月成長         |

| 行動               | 具體動作                                                                                           | 份量／頻率              |
| ------------------ | -------------------------------------------------------------------------------------------------- | ----------------------- |
| 商品頁             | 至少 5 張圖（含使用情境與尺寸對照）+ 1 支 15-30 秒影片；前三行寫出解決什麼問題                    | 每個主力商品            |
| 免運門檻           | 門檻設在目前 AOV 的 1.2-1.3 倍，購物車顯示「再買 NT$X 免運」                                       | 每季檢視                |
| 棄單提醒           | 1 小時、24 小時、72 小時各一封 Email 或 LINE 訊息（Shopify、SHOPLINE、91APP 內建或外掛）          | 自動化                  |
| 加購區塊           | 商品頁放「常一起買」與組合價                                                                       | 每個主力商品            |
| 評論邀請           | 到貨後 7 天自動請求評論，附照片評論給小回饋                                                        | 自動化                  |
| 門市會員           | 結帳時邀請加入 LINE 官方帳號會員（集點卡），每月發一則會員專屬訊息                                 | 每位來客；每月 1 則     |

## 客戶擴展 (Account Growth)

| KPI              | 量測方式                                | 參考區間         |
| ---------------- | --------------------------------------- | ---------------- |
| 客戶流失率       | 期間流失客戶 ÷ 期初客戶                 | 相對現況下降     |
| 擴充營收         | 既有客戶的升級與加購金額                | 相對現況成長     |
| 每位客戶轉介數   | 轉介新客 ÷ 客戶數                       | 相對現況成長     |
| NPS              | 0-10 分問卷：9-10 分比例 − 0-6 分比例   | 正值且逐季上升   |

| 行動           | 具體動作                                                                   | 份量／頻率                  |
| -------------- | -------------------------------------------------------------------------- | --------------------------- |
| 導入會議       | 成交後開導入會議 (Onboarding)，當場訂下第一個成果的日期                    | 成交後 7 天內               |
| 季度回顧       | B2B 每季業務回顧 (QBR)：展示成效數字，提出下季目標與擴充方案               | 每季每位客戶                |
| 補貨提醒       | 消耗型商品依使用週期自動提醒                                               | 自動化                      |
| NPS 分流       | 9-10 分請求轉介或評論；0-6 分由專人致電了解                                | 每季問卷；低分 48 小時內致電 |
