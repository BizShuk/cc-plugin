# 事業 (Business)

事業的成長沿著 AARRR 漏斗：獲客 → 啟用 → 留存 → 營收 → 推薦。
前提是產品市場契合 (PMF) 成立，底線是單位經濟 (Unit Economics) 算得過來。

## 診斷順序 (Diagnosis Order)

1. PMF 未成立（同期群留存曲線持續下滑、Sean Ellis 測試低於 40%）→ 只主攻 PMF，暫停付費獲客。
2. 啟用率低 → 主攻啟用；新用戶一進來就流失時，獲客只是浪費預算。
3. 留存差 → 主攻留存；先補漏水的桶子，再加水。
4. 以上都健康 → 主攻獲客，其次營收與推薦。
5. 任何時候出現 LTV ÷ CAC 小於 1 的通路 → 當月停損。

## 事業型態 (Business Types)

| 型態               | 優先子類別                   | 特有工具                                                     |
| ------------------ | ---------------------------- | ------------------------------------------------------------ |
| SaaS／App          | 啟用、留存、營收             | PostHog、Mixpanel、Stripe                                    |
| 電商／品牌 (DTC)   | 獲客、營收、留存（回購）     | Shopify、SHOPLINE、Meta Ads；成交細節另載入 `sales.md`       |
| 在地實體店         | 獲客（在地搜尋）、留存       | Google 商家檔案、LINE 官方帳號                               |
| 創作者／知識型     | 獲客（內容）、營收（產品階梯） | 社群平台（另載入 `social-media.md`）、電子報、課程平台     |

## 產品市場契合 (PMF)

| KPI              | 量測方式                                                              | 參考區間              |
| ---------------- | --------------------------------------------------------------------- | --------------------- |
| Sean Ellis 測試  | 「如果不能再用這個產品，你會多失望？」回答「非常失望」的比例          | 40% 以上              |
| 留存曲線         | 同期群 (Cohort) 留存是否在某個百分比走平                              | 走平即為 PMF 訊號     |
| 自然成長佔比     | 非付費來源的新用戶 ÷ 總新用戶                                         | 逐月上升              |

| 行動             | 具體動作                                                                                                 | 份量／頻率                  |
| ---------------- | -------------------------------------------------------------------------------------------------------- | --------------------------- |
| 用戶訪談         | 問過去發生的具體事件（「上次遇到這個問題是什麼時候？當時怎麼解決？」），避免推銷與「你會買嗎」 (The Mom Test) | 每 2 週 10 位           |
| Sean Ellis 問卷  | 用 Google 表單或 Typeform 發給近 2 週用過至少 2 次的用戶                                                 | 回收至少 30 份再判讀        |
| 收窄 ICP         | 找出回答「非常失望」者的共同輪廓，把目標客群收窄到這群人                                                 | 每次問卷後                  |

## 獲客 (Acquisition)

| KPI              | 量測方式                              | 參考區間             |
| ---------------- | ------------------------------------- | -------------------- |
| 每月新客數       | 後台或 GA4                            | 月對月成長           |
| 各通路 CAC       | 該通路花費 ÷ 該通路新客數             | 低於 LTV 的 1/3      |
| 通路佔比         | 各通路新客 ÷ 總新客                   | 單一通路不超過七成   |

| 行動             | 具體動作                                                                                                       | 份量／頻率                |
| ---------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------- |
| 通路篩選         | Bullseye 框架：列出所有可能通路 → 挑 3 個小預算測試 → 集中火力在效果最好的 1 個                                 | 每季一輪                  |
| SEO              | 每篇文章鎖定一個長尾關鍵字與搜尋意圖，用 Google Search Console 追蹤曝光與點擊                                  | 每週 1 篇                 |
| 付費廣告         | Meta Ads 或 Google Ads：固定受眾，測 3 組素材，每組至少跑 7 天再判斷，只保留 CPA 低於目標者                    | 每月一輪素材              |
| 在地搜尋         | Google 商家檔案 (Google Business Profile) 填滿所有欄位、上傳 10 張以上照片；48 小時內回覆每則評論；櫃台放評論 QR code | 每週發 1 則動態       |
| 合作曝光         | 與互補品牌或創作者聯名、交換曝光                                                                               | 每月 1 次                 |
| App 商店優化     | ASO：標題與副標題放主關鍵字，前 3 張截圖講核心價值                                                              | 每季檢視                  |

## 啟用 (Activation)

| KPI                    | 量測方式                                           | 參考區間         |
| ---------------------- | -------------------------------------------------- | ---------------- |
| 啟用率                 | 註冊後 7 天內完成關鍵動作 (Aha moment) 的比例      | 相對現況成長     |
| 價值實現時間           | 註冊到完成關鍵動作的時間 (Time-to-value)           | 相對現況縮短     |

| 行動             | 具體動作                                                                   | 份量／頻率          |
| ---------------- | -------------------------------------------------------------------------- | ------------------- |
| 定義 Aha moment  | 比較留存用戶與流失用戶第一週的行為差異，找出關鍵動作                       | 一次，每季檢視      |
| 精簡註冊         | 註冊表單只留必要欄位                                                       | 一次                |
| 引導清單         | 引導清單 (Onboarding checklist) 最多 3 步；空白頁面放範本或範例資料        | 一次                |
| 未啟用提醒       | 註冊 24 小時仍未啟用，自動寄一封只講一個下一步的 Email 或推播              | 自動化              |
| 漏斗量測         | PostHog、Mixpanel 或 GA4 建立註冊到關鍵動作的漏斗報表                      | 每週看一次          |

## 留存 (Retention)

| KPI                  | 量測方式                                  | 參考區間                      |
| -------------------- | ----------------------------------------- | ----------------------------- |
| D1／D7／D30 留存     | App 同期群報表                            | 相對現況成長                  |
| 月流失率             | 訂閱制：當月取消 ÷ 月初訂閱數             | 相對現況下降                  |
| 淨營收留存 (NRR)     | 既有客戶本期營收 ÷ 同批客戶上期營收       | B2B 訂閱 100% 以上為健康      |
| 回購率               | 電商：90 天內再購的顧客比例               | 相對現況成長                  |

| 行動             | 具體動作                                                                   | 份量／頻率          |
| ---------------- | -------------------------------------------------------------------------- | ------------------- |
| 同期群報表       | PostHog、Mixpanel 或 Amplitude 的留存報表                                  | 每月                |
| 生命週期訊息     | 依行為觸發 Email、推播或 LINE 訊息（Loops、Customer.io、LINE 官方帳號）    | 自動化              |
| 取消流程         | 取消前問離開原因，並提供暫停方案與降級方案                                 | 一次                |
| 年繳方案         | 提供年繳選項，降低月流失                                                   | 一次                |
| 流失訪談         | 約取消的用戶聊 15 分鐘                                                     | 每月 5 位           |

## 營收 (Revenue)

| KPI              | 量測方式                                  | 參考區間         |
| ---------------- | ----------------------------------------- | ---------------- |
| 營收月成長率     | MRR 或月營收的月對月變化                  | 相對現況成長     |
| ARPU             | 營收 ÷ 付費用戶數                         | 相對現況成長     |
| 毛利率           | (營收 − 直接成本) ÷ 營收                  | 相對現況成長     |
| LTV              | ARPU × 毛利率 ÷ 月流失率                   | CAC 的 3 倍以上  |

| 行動             | 具體動作                                                                         | 份量／頻率            |
| ---------------- | -------------------------------------------------------------------------------- | --------------------- |
| 新客漲價測試     | 只對新客提高 10-20%，觀察 30 天轉換率；既有客戶維持原價                          | 每年 1 次             |
| 價值指標分級     | 依用量、席位或功能分級；用量接近上限時提示升級                                   | 一次                  |
| 年繳優惠         | 年繳送 2 個月（約 83 折）                                                         | 一次                  |
| 扣款失敗追回     | Stripe Smart Retries + 扣款失敗通知 Email (Dunning)                               | 自動化                |
| 產品階梯         | 免費 → 低價入門 → 核心 → 高價；創作者：免費內容 → 電子書 → 課程 → 顧問           | 每半年補一階          |

## 推薦 (Referral)

| KPI              | 量測方式                                    | 參考區間         |
| ---------------- | ------------------------------------------- | ---------------- |
| 病毒係數 K       | 每位用戶邀請數 × 邀請轉換率                 | 相對現況成長     |
| 轉介新客佔比     | 轉介新客 ÷ 總新客                           | 相對現況成長     |
| NPS              | 0-10 分問卷：9-10 分比例 − 0-6 分比例       | 正值且逐季上升   |

| 行動             | 具體動作                                                                 | 份量／頻率      |
| ---------------- | ------------------------------------------------------------------------ | --------------- |
| 雙向獎勵         | 邀請者與被邀請者都得到好處，在滿意時刻觸發（完成首個成果、NPS 9-10 分）   | 一次建立        |
| 產出物帶品牌     | 用戶分享的報表或作品頁附「Made with X」連結                              | 一次建立        |
| NPS 問卷         | 推薦者請求評論或轉介                                                     | 每季            |

## 單位經濟 (Unit Economics)

| KPI              | 量測方式                                  | 參考區間                    |
| ---------------- | ----------------------------------------- | --------------------------- |
| LTV ÷ CAC        | 依通路分開計算                            | 3 倍以上（經驗值）          |
| CAC 回收期       | CAC ÷ (ARPU × 毛利率)，單位為月           | 12 個月以內                 |
| 現金跑道         | 現金 ÷ 月淨燒錢                           | 依募資計畫，至少 12 個月    |

| 行動             | 具體動作                                                                     | 份量／頻率      |
| ---------------- | ---------------------------------------------------------------------------- | --------------- |
| 通路試算表       | 各通路 CAC 與 LTV 並列在同一張試算表                                         | 每月            |
| 通路分級         | LTV ÷ CAC 小於 1 暫停；1-3 優化素材與落地頁；3 以上加碼                     | 每月            |
| 成本議價         | 與前 3 大供應商議價；追蹤退款率                                              | 每季            |

## 營運 (Operations)

| KPI                  | 量測方式                              | 參考區間         |
| -------------------- | ------------------------------------- | ---------------- |
| 每人營收             | 營收 ÷ 人數                           | 相對現況成長     |
| 每週手動重複工時     | 自行記錄                              | 相對現況下降     |
| 交付準時率           | 準時交付 ÷ 總交付                     | 95% 以上         |

| 行動             | 具體動作                                                                     | 份量／頻率        |
| ---------------- | ---------------------------------------------------------------------------- | ----------------- |
| SOP              | 列出每週重複前 5 名的手動工作，寫成 SOP                                      | 一次，每季更新    |
| 自動化           | 用 n8n 或 Zapier 串接重複流程，例如 表單 → CRM → 通知                        | 每月自動化 1 項   |
| 指標儀表板       | Google Sheets、Looker Studio 或 Metabase 放 5 個以內的核心 KPI               | 每週一看 30 分鐘  |
