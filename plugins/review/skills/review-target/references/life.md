# 生活 (Life)

個人成長的六個子類別。`恢復` 與 `體能` 是其他子類別的地基：睡眠長期不足時，先主攻恢復。

## 安全邊界 (Safety Boundary)

- 有傷病、慢性病、懷孕、胸痛或暈眩史：體能行動項目的第一項寫「開始前諮詢醫師」，起始份量減半。
- 訓練中出現尖銳痛（有別於肌肉痠）立即停止該動作。
- 財務只給行為層級建議（儲蓄率、自動轉帳、還債順序），投資標的交給使用者自行研究或諮詢專業顧問。
- 內容透露持續低落或自傷念頭時，停止成長計畫，改提供專業協助資源（台灣：1925 安心專線，24 小時）。

## 診斷順序 (Diagnosis Order)

1. 每個子類別自評 1-10 分，或由內容推斷。
2. 平均睡眠少於 7 小時 → 主攻恢復。
3. 每週身體活動少於 150 分鐘 → 體能列入主攻。
4. 其餘取分數最低、且最會拖累其他子類別的一項（例如財務壓力影響睡眠）。

## 體能 (Fitness)

| KPI                  | 量測方式                                          | 參考區間                                         |
| -------------------- | ------------------------------------------------- | ------------------------------------------------ |
| 每週中等強度活動分鐘 | Apple Watch 活動 App 或 Google Fit 的運動分鐘     | WHO：150-300 分鐘，另加每週 2 天肌力訓練         |
| 每日步數             | 手機健康 App 的 7 日平均                          | 7,000-10,000 步                                  |
| 引體向上最大次數     | 標準動作連續完成次數，每 4 週測一次               | 0 → 1 是第一個里程碑，10 下以上屬良好            |
| 伏地挺身最大次數     | 標準動作連續完成次數，每 4 週測一次               | 以自身現況為基準                                 |
| 下肢肌力             | 徒手深蹲連續次數，或槓鈴深蹲 5RM                  | 以自身現況為基準                                 |
| 5 公里跑步時間       | 跑錶或 Strava 紀錄                                | 以自身現況為基準                                 |
| 靜止心率             | 手錶晨間數值的 7 日平均                           | 成人 60-100 bpm，規律訓練者常更低                |
| 腰圍                 | 肚臍高度，每 2 週同一時段量                       | 國健署：男性 < 90 cm、女性 < 80 cm               |

訓練紀錄工具：Hevy 或 Strong（肌力）、Strava（跑步）、Apple 健康（彙整）。

### 引體向上 (Pull-up)

標準動作：正手握、略寬於肩；從手臂完全伸直的懸吊開始，拉到下巴高於槓；身體不擺盪、不踢腿。

| 現況                  | 動作                                                            | 份量                                   | 頻率                  |
| --------------------- | --------------------------------------------------------------- | -------------------------------------- | --------------------- |
| 0 下，懸吊少於 20 秒  | 死懸吊 (Dead hang) + 肩胛下壓 (Scapular pull-up)                | 懸吊 3 × 20-30 秒；肩胛下壓 3 × 8      | 每週 3 次             |
| 0 下，懸吊達 30 秒    | 離心引體 (Negative)：跳到頂端，花 3-5 秒慢放到底 + 反向划船 (Inverted row) | 離心 3 × 3-5；划船 3 × 8-12   | 每週 3 次，間隔 48 小時 |
| 0 下，有彈力帶        | 彈力帶輔助引體 (Band-assisted)                                  | 3 × 5-8，每 2 週換細一級彈力帶         | 每週 3 次             |
| 1-4 下                | 分散練習 (Grease the groove)：一天多組，每組只做最大次數的一半  | 每天 5-8 組，組間至少 15 分鐘          | 每週 5 天             |
| 5-9 下                | 次最大量組數：每組做到最大次數減 2                              | 4 組，每週總次數 +2                    | 每週 2-3 次           |
| 10 下以上             | 負重引體 (Weighted) 或 L-sit 引體                               | 負重 +5 kg，3 × 5                      | 每週 2 次             |

完成判準：每 4 週重測最大次數，目標 +1-3 下。

### 伏地挺身 (Push-up)

標準動作：頭到腳跟一直線；手肘與身體約 45 度；胸口下到離地約一拳高。

| 現況      | 動作                                                  | 份量                   | 頻率        |
| --------- | ----------------------------------------------------- | ---------------------- | ----------- |
| 0-4 下    | 上斜伏地挺身 (Incline)：手撐桌面或椅面，每 2 週降低高度 | 3 × 8-12              | 每週 3 次   |
| 5-14 下   | 標準伏地挺身，下放 3 秒                               | 4 組 × (最大次數 − 2) | 每週 3 次   |
| 15-30 下  | 下斜伏地挺身 (Decline，腳墊高) 或窄距                  | 4 × 8-12              | 每週 2-3 次 |
| 30 下以上 | 弓箭步伏地挺身 (Archer) 或穿負重背心                  | 每側 3 × 6-8          | 每週 2 次   |

### 深蹲 (Squat)

標準動作：雙腳與肩同寬、腳尖微外開；臀部往後下坐到大腿至少與地面平行；膝蓋與腳尖同方向；腳跟貼地。

| 現況                  | 動作                                           | 份量                                   | 頻率        |
| --------------------- | ---------------------------------------------- | -------------------------------------- | ----------- |
| 徒手深蹲少於 20 下    | 箱上深蹲 (Box squat)：坐到椅子後站起           | 3 × 10-15                              | 每週 3 次   |
| 徒手深蹲達 20 下      | 高腳杯深蹲 (Goblet squat)，手持啞鈴或壺鈴      | 3 × 8-12，能做滿 12 下就加 2 kg        | 每週 2-3 次 |
| 有槓鈴與教練指導      | 背蹲舉 (Back squat) 線性進步                   | 3 × 5，每次 +2.5 kg，直到停滯          | 每週 2-3 次 |

## 財務 (Finance)

| KPI            | 量測方式                                   | 參考區間                        |
| -------------- | ------------------------------------------ | ------------------------------- |
| 儲蓄率         | (稅後收入 − 支出) ÷ 稅後收入，按月計       | 20% 以上（50/30/20 法則）       |
| 緊急預備金     | 活存 ÷ 月支出                              | 3-6 個月                        |
| 高利負債餘額   | 信用卡循環、信貸                           | 歸零                            |
| 淨資產         | 資產 − 負債，每月同一天記錄                | 月對月成長                      |
| 被動收入覆蓋率 | 被動收入 ÷ 月支出                          | 長期朝 100% 前進                |
| 訂閱支出       | 每月訂閱總額                               | 相對現況下降                    |

| 行動           | 具體動作                                                                           | 份量／頻率                           |
| -------------- | ---------------------------------------------------------------------------------- | ------------------------------------ |
| 建立現況       | 用麻布記帳 (Moneybook)、CWMoney 或試算表記帳，分類不超過 10 類                      | 連續 30 天                           |
| 先存再花       | 發薪日設定銀行預約轉帳，轉到另一個不綁卡的帳戶 (Pay yourself first)                | 從收入 10% 開始，每季 +2%            |
| 還債順序       | 雪崩法 (Avalanche) 先還利率最高；需要成就感時用雪球法 (Snowball) 先還餘額最小        | 每月                                 |
| 訂閱清查       | 檢查 App Store 訂閱與信用卡帳單，30 天沒用的取消                                   | 每月 1 日                            |
| 長期投入       | 定期定額投入分散的指數型工具（行為建議，具體標的由使用者自行研究）                 | 每月固定日                           |
| 收入端         | 加薪、轉職、副業，接學習與職涯子類別                                               | 每季檢視                             |
